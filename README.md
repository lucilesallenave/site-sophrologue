# Site de Lucile Sallenave, sophrologue

Site vitrine statique (HTML/CSS, sans outil de construction) : séances en visio partout en France et à domicile en Seine-et-Marne. Ambiance « Aube ».

- `index.html` : page d'accueil (séances, visio, à propos, thèmes, questions, réservation)
- `mentions-legales.html`
- `assets/style.css` : styles et couleurs (variables en tête de fichier)
- `assets/photos/` : photos à ajouter

Les éléments entre crochets `[…]` sont à remplacer par les informations de Lucile.
